# ВЕРТЭКС — главная страница

Локальный прототип на React 19, TypeScript, Vite и Storybook 10. Backend не требуется. Все используемые изображения, SVG, шрифт и видео находятся в проекте.

## Запуск

Требуется Node.js 22.12+.

```sh
npm ci
npm run dev
npm run storybook
```

Главная: http://127.0.0.1:5173/  
Storybook: http://127.0.0.1:6006/

Команды запускаются в отдельных терминалах. Storybook содержит токены, типографику, кнопки, поля и ошибки, карточки техники, семь анимированных карточек, форму, навигацию, подвал и два варианта главной.

## Макеты и реализация

- Figma: файл `pW3maaNJigInMLmgMH3VEn`, desktop `53:2794` (1440 × 5243), mobile `60:1216` (375 × 7866), меню `63:1595`.
- `src/tokens.css` — цвета, шкала отступов, радиусы и адаптивная типографика Manrope. Переключение мобильного режима на 767 px.
- `src/components.tsx` — общие компоненты страницы и Storybook.
- `src/App.tsx` — секции главной, локальный каталог, фильтрация.
- `src/layout.css` — актуальная адаптация: сетка, увеличенный контент, фиксированная шапка, sticky-кнопка каталога и раскрытие подвала.
- `asset-manifest.json` — соответствие локальных ассетов узлам Figma. Фото использованы из макета; API-ссылок Figma во время работы сайта нет.
- Анимация семи карточек основана на раскрытии изображения из силуэта на fabrikant.su, включая крановщиков и обучение; остальные появления используют плавность референса tesart.ru. Hover и клавиатурный фокус раскрывают карточку, на touch раскрытие запускается при появлении. Учитывается `prefers-reduced-motion`.

После правок: хиро занимает `100dvh`, шапка фиксирована и скрывается по направлению скролла. Кнопка «Вся техника» закреплена только в пределах каталога: на ПК сверху, на мобильном в 24 px от нижнего края экрана. Подвал раскрывается при скролле с закреплённой фотографией и уменьшением масштаба 1.3 → 1. Отступы — 24 px на всех ширинах. Сетка Figma: 12 колонок, gutter 24 px; мобильная — 2 колонки, исходный inset 16 px заменён на 24 px по запросу. До 991 px навигация переключается на меню.

Контент увеличен общими токенами: desktop H1 56/64, H2 40/48, H3 28/36, body 18/28; mobile H1 32/40, H2 28/36, H3 24/32, body 16/24. Для низких окон размеры первого экрана уменьшаются, чтобы информация помещалась под шапкой.

Каталог намеренно повторяет четыре карточки из Figma. Фильтры работают с этими локальными данными. Попап техники удалён. Все ссылки разделов, услуг, заявок, техники и правовых документов открывают страницу 404 в стиле сайта; логотип и кнопка «На главную» возвращают на `/`. Якорных ссылок нет. Форма на главной проверяет имя, телефон, необязательный email и согласие; показывает демонстрационный результат без сохранения и отправки данных.

В `src/navigation.css` оформлены раскрывающиеся меню и селекты: белые панели, зелёные состояния, управление клавиатурой, закрытие снаружи и по Escape. Списки фильтров раскрываются вверх при нехватке места. Кнопка «Обсудить задачу» имеет ширину по содержимому, боковые паддинги 24 px и прилегает к правому краю. Плавный скролл реализован через Lenis (`src/useSmoothScroll.ts`), отключается при reduced motion и блокируется при открытом мобильном меню. Сенсорная прокрутка остаётся нативной.

Уточнения интерфейса: кнопка шапки использует чёрный `#171717` и белый текст из Figma `53:2816`; hover плавный, 350 мс. Открытое мобильное меню сохраняет координаты логотипа и управляющей кнопки, а содержимое появляется и закрывается с анимацией. У шеврона «Услуги» в подвале gap 4 px. На 404 удалена зелёная подпись, заголовок поднят. Карточки сопровождения — `article` без ссылок, с паддингами сверху и снизу 16 px и одинаковой высотой по самой высокой; на мобильном раскрытие изображения отключено.

В мобильном меню список услуг раскрывается целиком; внутренние отступы первой и последней строк одинаковые. Прокручивается всё меню. До 767 px карточки хранения и ремонта статичны: фото не раскрываются при скролле, наведении или фокусе, силуэты иконок окрашены в зелёный через CSS-маски. На ПК сохранена исходная анимация.

На мобильном карточки крановщиков и обучения постоянно показывают фотографию, белый текст и белую кнопку с чёрным текстом; раскрытие по скроллу и наведению отключено, анимация заголовков сохранена. Иконки сопровождения на мобильном однотонные, с заливкой `--primary-20`, совпадающей с обводкой карточек.

`src/useHeadingReveal.ts` реализует [Serega Gentle](https://github.com/mishanaer/deslop/tree/main/serega/serega-gentle) для H1/H2: подъём отдельных букв на 15 px, 500 мс, stagger 15 мс, `cubic-bezier(0.2,0.8,0.2,1)`, без blur. Каждый заголовок раскрывается один раз при появлении. Сохранены переносы, неразрывные пробелы, доступное название и статичный текст при reduced motion. В режиме визуального сравнения анимация отключена.

## Видео

Использован предоставленный MP4. Начало до 6.0 секунды и финальная заставка после 25.6 секунды исключены физически. Результат: 19.6 секунды, 1440 × 810, H.264, без звуковой дорожки, faststart. Исходник не изменён.

Для повторной подготовки:

```sh
node scripts/prepare-video.mjs "/absolute/path/to/original.mp4"
```

При блокировке autoplay остаётся poster. При reduced motion используется статичное изображение.

## Проверка

```sh
npm run build
npm run build-storybook
npm audit
```

Результаты проверки: `QA.md`. Скриншоты, наложения и карты различий находятся в локальной папке `qa/` (исключена из Git).

Для повторяемой визуальной проверки в dev-режиме: `/?visual=figma`. Видео заменяется фотографией макета, появления отключаются, ремонт показан в раскрытом состоянии Figma. В production этот параметр не активируется. При наличии эталонных экспортов в `design-reference/` и скриншотов в `qa/` сравнение выполняется командой `node scripts/compare.mjs`.

## GitHub и сервер

Репозиторий: https://github.com/Ankapich2/vertex-website  
Публичный просмотр: https://ankapich2.github.io/vertex-website/

Публикация выполняется бесплатно на GitHub Pages. Отдельный сервер не требуется. После каждого push в `main` workflow `.github/workflows/deploy.yml` устанавливает зависимости, собирает сайт и публикует его. Секреты для этого workflow не нужны.

```sh
npm ci
npm run build
npm run build-storybook
```

Для GitHub Pages workflow задаёт `VITE_SITE_BASE=/vertex-website/`. Изображения, видео, шрифты и внутренние ссылки учитывают этот префикс. На обычном статическом сервере можно разместить `dist/` в корне сайта со стандартной сборкой без переменных окружения. Сборка создаёт `dist/404.html`; GitHub Pages использует его для отсутствующих адресов. Пример конфигурации Nginx сохранён в `deploy/nginx.conf.example`. В локальном Vite тот же экран работает через SPA fallback со статусом 200. Storybook собирается отдельно в `storybook-static/` и пока не публикуется. База данных и серверное приложение не нужны.

В Git включаются исходники, `public/`, конфигурация, manifests и `package-lock.json`; не включаются `node_modules/`, сборки, локальные скриншоты и временные экспорты Figma. Публичная форма остаётся демонстрационной и не отправляет данные.
